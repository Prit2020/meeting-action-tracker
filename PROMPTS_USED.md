# Prompts Used During Development

Below are representative prompts used to guide development.

## Architecture & Planning
- Design a scalable folder structure for a full-stack application.
- How should frontend and backend communicate in production?
- Best practices for structuring React components.

## Backend Development
- Create an Express API to extract action items from text.
- How to structure MongoDB models for transcripts and tasks.
- Implement error handling and status endpoints.

## AI Integration
- How to extract structured action items from meeting transcripts.
- Best prompt structure for extracting tasks, owners, and due dates.

## Frontend Development
- Build a clean dashboard layout with sidebar and header.
- Implement task filtering and editing functionality.
- Create reusable UI components for tables and buttons.

## UX Improvements
- Improve user feedback with toast notifications.
- Best practices for loading states and error handling.
- Improve usability and accessibility of forms and filters.

## Note
Agent responses, API keys, and sensitive data are intentionally not included for security and privacy reasons.
